### 1. Постановка задачи и цели исследования

Основной целью данной лабораторной работы является программная реализация, тестирование и всесторонний сравнительный анализ классических прямых методов решения систем линейных алгебраических уравнений вида Ax = b, где A — квадратная невырожденная матрица размерности n x n, x — искомый вектор, b — заданный вектор правой части.

**В рамках исследования необходимо:**

1. Реализовать базовый метод исключения Гаусса (прямой и обратный ход).
2. Модифицировать метод Гаусса добавлением алгоритма выбора главного (ведущего) элемента по столбцу для повышения вычислительной устойчивости.
3. Реализовать алгоритм факторизации матрицы — LU-разложение, а также сопутствующие алгоритмы прямой и обратной подстановки.
4. Провести профилирование (замер времени) алгоритмов на матрицах случайных чисел для оценки реальной вычислительной сложности.
5. Исследовать поведение алгоритмов при решении систем с множественными правыми частями.
6. Проанализировать накопление ошибок машинного округления и влияние числа обусловленности матрицы на точность решения, используя тестовые матрицы Гильберта.

### 2. Математическое описание и анализ алгоритмов

#### 2.1 Базовый метод Гаусса (без выбора ведущего элемента)

Метод представляет собой последовательное исключение переменных и состоит из двух этапов:

* **Прямой ход (триангуляция):** Матрица A с помощью элементарных преобразований строк приводится к верхнетреугольному виду U. На k-м шаге для всех строк i > k вычисляется множитель m_ik = a_ik / a_kk. Затем из i-й строки вычитается k-я, умноженная на m_ik.
* **Обратный ход:** Решение полученной треугольной системы Ux = c выполняется снизу вверх. Вычисления производятся по формуле:
x_i = (b_i - Сумма(u_ij * x_j)) / u_ii

**Сложность:** Прямой ход требует примерно (2/3) * n^3 арифметических операций, обратный — O(n^2). Общая асимптотическая сложность: O(n^3).

#### 2.2 Метод Гаусса с выбором ведущего элемента (Pivot)

Главный недостаток базового метода — возможное деление на нуль или на очень малое число a_kk, что в арифметике с плавающей точкой приводит к катастрофической потере точности (возрастанию погрешностей округления).

* **Модификация:** Перед выполнением k-го шага прямого хода алгоритм просматривает k-й столбец (начиная с диагонали и ниже) и находит элемент, максимальный по абсолютному значению. Строки меняются местами. Это гарантирует, что мультипликатор m_ik всегда будет по модулю меньше или равен 1, что сдерживает рост вычислительной ошибки. Сложность поиска максимума добавляет O(n^2) операций, не меняя общую асимптотику O(n^3).

#### 2.3 LU-разложение

Метод основан на представлении исходной матрицы в виде произведения A = LU, где L — нижнетреугольная матрица с единицами на главной диагонали, а U — верхнетреугольная матрица. Элементы матриц вычисляются по формулам:

* Для верхнетреугольной матрицы U:
u_ik = a_ik - Сумма(l_ij * u_jk)
* Для нижнетреугольной матрицы L:
l_ki = (a_ki - Сумма(l_kj * u_ji)) / u_ii

**Решение системы:** После разложения исходная задача Ax = b (или LUx = b) разбивается на два этапа со сложностью O(n^2) каждый:

1. Прямая подстановка: решение Ly = b относительно вектора y.
2. Обратная подстановка: решение Ux = y относительно искомого вектора x.

**Асимптотика:** Само разложение требует примерно (2/3) * n^3 операций (выполняется один раз). Решение системы для каждой новой правой части — O(n^2).

### 3. Оценочные метрики

Для объективной оценки точности реализованных алгоритмов использовались следующие нормы и метрики:

1. **Евклидова норма вектора:** Базовая метрика длины вектора в n-мерном пространстве.
||v||_2 = sqrt(v_1^2 + v_2^2 + ... + v_n^2)
2. **Относительная погрешность:** Показывает реальное отклонение найденного приближенного решения (x_approx) от известного точного решения (x).
Погрешность = ||x_approx - x||_2 / ||x||_2
3. **Невязка:** Характеризует, насколько точно найденное решение удовлетворяет исходному уравнению. Вычисляется путем подстановки ответа обратно в систему.
Невязка = ||A * x_approx - b||_2

### 5. Итоговые выводы

1. **Анализ вычислительной сложности:** Эмпирические замеры времени полностью подтвердили теоретическую асимптотику O(n^3) для рассмотренных прямых методов.
2. **Преимущество LU-факторизации:** Использование LU-разложения абсолютно оправдано в инженерных задачах, где физическая модель (матрица коэффициентов) неизменна, а начальные/граничные условия (вектор правой части) меняются многократно. Выигрыш в производительности колоссален.
3. **Роль ведущего элемента:** Алгоритм выбора главного элемента по столбцу требует незначительных накладных расходов времени, но существенно стабилизирует процесс вычислений, снижая погрешности округления. Базовый метод Гаусса использовать на практике не рекомендуется.
4. **Иллюзия малой невязки:** На примере матриц Гильберта наглядно продемонстрировано коварство плохо обусловленных систем. Малая норма невязки (около нуля) **не гарантирует** близости найденного решения к точному. Потеря точности на таких системах — фундаментальная проблема арифметики конечной разрядности, а не программная ошибка алгоритма.
